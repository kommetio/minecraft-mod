# Minecraft mod

The goal of this project is to create a Minecraft mod.

The mod adds a peaceful wandering White Silhouette entity: a plain white cubic
head and rectangular torso, without arms, legs, or facial features.

Use the White Silhouette Spawn Egg from the Creative inventory's Spawn Eggs tab
to place it, or run `/summon cat_widmo991:silhouette`. It does not spawn naturally.
